# Beeline changelog (extension versions; called Tilenest Bookmarks before 2.0.0)

| Version | What changed |
|---|---|
| 2.5.4 | **New logo** (from Stitch): a bee whose body is a bookmark ribbon, navy and golden, on a light rounded chip. Used for the extension icons (16 to 128 px) and the top bar. Originals and the 512 px mark are in `design/logo/`. |
| 2.5.3 | **Ready for Firefox Add-ons.** The Firefox extension id is now `beeline-bookmarks@rosariosai.github.io` (the old placeholder id is gone; Firefox treats this as a new add-on, so export a backup from the old one and import it), and the Firefox package no longer claims Android support (desktop only). |
| 2.5.2 | **Real addresses.** The built-in documentation bookmarks now point to the GitHub repository and to the blog (The Daily Calf); README and site link to both. |
| 2.5.1 | **Touch drag and drop** (Stitch interaction spec). On a phone, press and hold a bookmark for 350 ms to lift it (short vibration, slight enlargement and shadow, dashed ghost slot where it was); moving more than 8 px before that is a normal scroll; drag near the top or bottom edge to auto-scroll; release to reorder, move to another group or make it Preferred. Mouse dragging works as before (6 px). The bookmark ⋯ button still opens the menu, and "Move to group" is there for groups out of view. Constants are in `src/ui/dragConfig.ts`. Not done: cancel by a second finger, and a spring return animation. |
| 2.5.0 | **Phone layout** (from the Stitch developer spec, breakpoint 720 px). Two-row top bar (menu, logo, hidden items, settings; then full-width search and the View button); round **+ Add bookmark** button at the bottom right (the Add, Import/Export and Sync buttons leave the top bar on phones); Import / Export and Sync now sit in a footer pinned to the bottom of the side drawer; the View menu and the bookmark menu open as **bottom sheets** with a handle and a dimmed background; group-header icon buttons and sidebar rows are at least 44 px; the bookmark ⋯ button is always visible on touch screens; search shows a **Cancel** button; inputs are 16 px (no zoom on iPhone); bottom padding keeps the last row clear of the + button and the home bar. Desktop is unchanged. Touch drag-and-drop gestures are not part of this release. |
| 2.4.2 | **Accessibility and View menu polish** (from the design review). The View menu says **Quick looks · Custom** as soon as you change a setting a Quick look controls, and only a matching look is marked; the menu scrolls instead of being cut off on short windows. Contrast fixed in the light theme (active sidebar entry, counts, selected search row) and for selected tags and filter chips in both themes; an automated check (axe, WCAG A and AA) now reports nothing on the dashboard, View menu, Settings, Import / Export, tag filter and search, in dark and light. The selected search result has a clear accent bar. Filled blue buttons use a slightly deeper blue in the dark theme for readable white text. |
| 2.4.1 | **Cleaner built-in links and Settings > Restore.** Each browser now shows only its own "Personal extensions" link (a Chrome link no longer appears in Brave, also after importing a Chrome backup). The Firefox link opens `about:debugging#/runtime/this-firefox` (an untouched old `about:addons` link is migrated on start). New **Beeline documentation** bookmarks (GitHub and blog), the same in every browser, visible, in Ungrouped and deletable; the addresses are placeholders until the project is published, and an untouched placeholder is replaced automatically once the real address is set in `DOC_LINKS`. New button Settings > Bookmarks > **Restore built-in links** recreates any missing built-in link without touching other bookmarks. Open-source files added: MIT licence, README, CONTRIBUTING, SECURITY, CI workflow, issue and PR templates, privacy policy rewritten for Beeline. |
| 2.4.0 | **Personal extensions links.** Browser pages (`chrome://extensions`, `brave://extensions`, `about:addons`, also `edge://`, `vivaldi://`, `opera://`) are now accepted as bookmark addresses and are opened through the extension API (a normal link is blocked by browsers). Every profile gets once a hidden bookmark "Personal extensions (Chrome / Brave / Firefox)" in its Top group, with fixed ids so syncing does not duplicate them. Show them with the Hidden eye; delete them like any bookmark and they stay deleted. |
| 2.3.1 | All top-bar buttons (Add, View, Hidden, Sync, Import/Export, Settings) have one common size (64 x 44); the top sidebar entries (All bookmarks, Preferred) are bold; in the No boxes (raw) view a bookmark already shown in the Preferred bar is not repeated below. |
| 2.3.0 | **Bee logo.** New Beeline logo: a bee whose body is a bookmark ribbon (vector in `design/logo/`), used for the extension icons (16-128 px), the browser-tab icon and the top bar, with the wordmark "beeLine" (yellow "ee"). |
| 2.2.1 | Raw view can be reordered by dragging (an icon dropped on another takes its place and joins its group; numbers follow). View menu made clearer: Quick looks (Classic / Compact / Dense), wording "Bookmarks look like" and "Groups are shown as" (Boxes / Side by side / No boxes), a hint line, and Group headers hidden when there are no boxes. INSTALL gets a short "How to organise" section. |
| 2.2.0 | **Raw view.** View menu > Groups > **Raw**: groups disappear completely and every visible bookmark appears in one flat, compact grid (combine with Icons layout, Small size and Numbers for the densest view). Bookmarks can still be opened, edited and found by number; to reorder or move them, switch back to Stacked or Side by side. |
| 2.1.0 | **Numbers (TV style) and hideable group headers.** View menu > "Numbers on bookmarks": every visible bookmark shows a number in the order you see them (Preferred bar first, then groups in order); type the number in the search box and press Enter to open it (works even when the badges are hidden). View menu > "Group headers" > Hide removes the header bars (name, buttons) so icons get more room; each group keeps a coloured top edge and collapsed groups open up. Both are view settings for sync. |
| 2.0.0 | **New name: Beeline** (was Tilenest Bookmarks). The name appears in the top bar, the extension name, texts, backup file names (`beeline-backup-...`) and the suggested sync file name (`beeline-sync.json`). Unchanged on purpose so nothing breaks: your data and settings, the Firefox add-on id, the backup format (old Tilenest backups import, new ones still read by older versions) and an existing `tilenest-sync.json`. The bee logo comes later (the B stays for now). |
| 1.21.0 | Hidden button is just a colourful eye (orange lids, blue iris) with the count. While hidden items are concealed a dark bar crosses the eye; when they are shown the eye is clear and the button gets an amber frame. |
| 1.20.0 | View and Import / Export are icon-only buttons (a layout-grid icon and an up/down arrows icon, tooltips "View" and "Import / Export"). |
| 1.19.1 | The Add bookmark button is only the coloured ribbon-and-star icon (tooltip "Add bookmark"), no text. |
| 1.19.0 | Every top-bar button has its own colour: Add bookmark (blue, with a bookmark-ribbon-and-star icon), View (purple), Hidden (teal with a crossed-out eye, amber open eye when hidden items are shown), Import / Export (green), Sync (cyan), Settings wheel (pink). |
| 1.18.0 | Top bar simplified: Settings is just the ⚙ wheel; the view button is a purple **◫ View** (its tooltip tells the current choice). |
| 1.17.1 | Settings cards are numbered 1 to 7 (matching the docs). The Comfortable/Compact **density** option is removed: it did not fit with the Tiles / List / Icons layouts and sizes (old backups that contain it still import). |
| 1.17.0 | **Settings redesigned.** Every section is a framed card with its own colour and a darker header band: This browser, Sync, Preferred, Bookmarks, New tab behaviour, Your data, Display. The redundant display options (layout, size, groups per row, side panel) are gone from Settings: they live in the ◫ View menu and the ☰ button; Theme and Density remain in a Display card at the bottom. |
| 1.16.3 | Fix: Top Chrome / Top Brave / Top Firefox appeared twice after syncing (each browser had created its own). Same-named Top groups are now merged into one (the oldest is kept, bookmarks are moved into it) at start-up and in every sync; both browsers reach the same result. Other groups are never merged. |
| 1.16.2 | Top Chrome, Top Brave and Top Firefox now exist in every browser profile, new or existing (created empty once if missing; if you delete one later it stays deleted). Each is shown in its own browser, the others under 👁 Hidden. |
| 1.16.1 | Top bar: the sync button reads "Sync" and shows "Synced" while the pointer is over it. The Hidden button has a bigger eye: open and amber (with a SHOWN tag) when hidden items are visible, closed and muted (OFF tag) when they are not. |
| 1.16.0 | **Tags on tiles are optional.** Settings > Bookmarks > "Show tags on big tiles" and a "Tags on tiles" row in the ◫ View menu (shown for Tiles). List and Icons never show tags. Tags stay searchable (#tag), filterable in the side panel and editable. Counts as a view setting for sync. |
| 1.15.0 | **Save site icons into my bookmarks** (Settings > Your data, Chrome and Brave): copies the site icons the browser already has into Tilenest as stored images, so they travel in backups and sync files and show in Firefox. Nothing is downloaded. Sites the browser has no icon for stay letters. |
| 1.14.0 | **Choose what is synced** (Settings > Sync > What is synced): bookmarks/groups/tags always; layers Order and Preferred, Group look, Hidden items, View settings can be switched on or off per browser, with presets Content only / Recommended / Everything. A layer that is off stays local and the file keeps the other browsers' values. |
| 1.13.2 | Brave was sometimes treated as Chrome (so "Top Brave" stayed hidden). Detection is stronger and Settings > This browser lets you set Chrome / Brave / Firefox by hand (per browser, not synced). |
| 1.13.1 | Settings > Sync now tells Brave users how to enable the browser feature Brave switches off by default (brave://flags/#file-system-access-api), instead of showing the Firefox text. |
| 1.13.0 | **Promote a group to Preferred.** Group menu > "★ Promote group to Preferred" (or the checkbox in Colour, icon, browsers…): all the group's bookmarks appear in the Preferred bar, in the group's order (drag to reorder inside the group), and the group itself is hidden automatically (badge "★ in Preferred", still under 👁 Hidden). Meant for each browser's own Top group; normal groups keep starring single bookmarks. Bookmarks of a promoted group stay searchable. |
| 1.12.0 | **Size applies to every layout.** "Tile size" is now just "Size" (View menu and Settings): Small / Medium / Large changes the bookmarks in Tiles, List and Icons, and the Preferred buttons. |
| 1.11.3 | Preferred bookmark names now look exactly like names in the groups (same size and weight, same rule for empty titles). |
| 1.11.2 | Fix: "show the site name for bookmarks without a title" now behaves the same in Tiles and List (it used to work in List only) and is applied live to existing bookmarks, no longer only when saving. |
| 1.11.1 | Group headers are now a darker, gradient band in the group's colour, clearly separated from the bookmarks below; soft gradients on the page background, Preferred Launchpad, side panel and the primary button. |
| 1.11.0 | **Drag group windows.** Each group header has a ⠿ handle: drag the whole group window onto another one to reorder groups right in the big area (keyboard: focus the handle, Space, arrows, Space). The side-panel list still works too. |
| 1.10.0 | **One View menu.** The separate Columns and layout buttons are replaced by a single "◫ View" button (shows the current choice) with pictures: Bookmarks as Tiles / List / Icons, Groups Stacked / Side by side, and Tile size for Tiles. |
| 1.9.0 | **Your own group icons:** type any emoji or 1–4 letters in the group Icon field and click "+ Add to my icons"; it stays in the picker for every group (× on hover removes it). Stored with the settings of this browser, and included in backups. |
| 1.8.1 | New logo: a big bold white B on a blue rounded square (extension icons and the top bar). |
| 1.8.0 | **Icons-only layout** (layout button cycles Tiles, Compact, Icons; also in Settings): a dense grid of icons, name and URL in the tooltip, ⋯ menu on hover. **Group icons:** picker with 40 icons plus any emoji (group menu > Colour, icon, browsers…). |
| 1.7.1 | Fix: the group list in the Add/Edit dialog was unreadable in dark mode (translucent dropdown), so a group could not be chosen; now solid. A fresh install now starts with Top Chrome / Top Brave / Top Firefox (the Settings button is gone). |
| 1.7.0 | **Duplicate a bookmark** (bookmark menu > Duplicate: copy placed right after the original, opens in Edit so you can change the URL, e.g. several Home Assistant dashboards). **Top Chrome / Top Brave / Top Firefox:** a fresh install has these three groups at the top; a group limited to other browsers now counts as *hidden* there (dimmed under 👁 Hidden, "Also show in this browser" in its menu) instead of vanishing. Preferred stays shared by all browsers. |
| 1.6.0 | **Groups per browser.** Each group has "Show this group in: Chrome / Brave / Firefox" (group menu > Colour, icon, browsers…). A group limited to other browsers is treated as hidden in this one (dimmed under 👁 Hidden) and keeps syncing (changed in 1.7.0). Brave is told apart from Chrome automatically. Example: a "Chrome top" group that only Chrome shows, a "Brave top" group only Brave shows. |
| 1.5.0 | **Sync is for Chrome and Brave only.** The manual Firefox file flow was removed (Firefox cannot keep a file linked); Firefox now shows how to copy bookmarks with Import / Export. Simpler code and docs. |
| 1.4.1 | **Sync fix (Firefox / manual file flow):** a bookmark added in Firefox could disappear again when you later picked the old file instead of the saved merged one, because it was mistaken for "deleted elsewhere". In the manual flow the last agreed state is now what the file contained when it was read. Clearer "save the downloaded file over the old one" message and a tip to set Firefox to ask where to save downloads. Tests added. |
| 1.4.0 | **Sync between browsers through one file** (Settings > Sync between browsers). Link a file in a cloud-synced folder; each browser merges its changes into it (three-way merge: changes on both sides are combined, deletions propagate, an edit beats a delete, bookmarks edited on both sides: the newer wins; open counts are not lost). First sync matches the same bookmarks/groups/tags by URL and name, so no duplicates. Chrome/Brave keep the file linked (auto-sync ~5 s after a change; one click to re-allow access after a browser restart). Firefox: pick the file, merge, save the downloaded file over the old one. Preferred flags, group colours/emoji, collapsed groups and custom icons travel too. New `docs/INSTALL.md` for Chrome, Brave and Firefox. |
| 1.3.1 | **Light theme polish**: Apple-style light look (soft grey canvas, white cards, hairline borders, light glass top bar, softer shadows, lighter dialog backdrop, tuned accent and star colours). Works for both "Light" and "Match my system". |
| 1.3.0 | **Collapsible groups**: ▾/▸ button in each group header, "Collapse group"/"Expand group" in the group menus, and "Collapse all groups"/"Expand all groups" in the side panel. A collapsed group shows only its name and count; it is remembered, kept in backups, and always shown open when you filter by tag, search, or open the group itself. |

Optional quiet **Often used** row (Settings > Preferred). **Group colour and emoji** (group menu > Colour and emoji). Glass top bar, rounded group cards, new dialogs, menus and toast. Dark is the default theme. Backups keep the new fields; older backups still load. |
