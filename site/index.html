Features

What it does

Six simple ways Beeline keeps your frequently visited sites organized and accessible.

Preferred launchpad

Mark key bookmarks as Preferred to display them in a dedicated high-priority row right at the top of every new tab.

Groups with colours and emoji

Organize bookmarks into visual categories such as Work, Reading, Learning, and Fun with distinct color bars and emoji labels.

Tiles, list or icons

Switch display density between large touch tiles, compact horizontal lists, or minimal icon matrices to fit your screen size.

Flat "No boxes" view with numbers

Remove enclosing cards and display quick numeric badges on every icon for instant keyboard-driven jumping.

Fast search and tags

Press "/" to focus search instantly across titles, addresses, and custom tags with highlighted match segments.

Hide and unhide

Stow away rare links or sensitive workspaces. Toggle the eye button in the top bar to reveal or conceal them on demand.

Specifications

Requirements & Permissions

Lightweight by design. No background daemons and no account systems.

Browser Version

A current release of Chrome, Brave, or Firefox (version 128 or newer). Nothing else to install.

Source Builds

If building directly from source code, Node.js version 20 or newer is required.

Optional Permission: Bookmarks

Requested only when you click "Import my browser bookmarks" to read your existing tree into Beeline.

Optional Permission: Favicon

Used solely to display local site icons from your browser cache for matching bookmark URLs.

Setup

Install

Step-by-step instructions to load Beeline in your desktop browser.

  1. Open extensions page: Navigate to chrome://extensions (or brave://extensions).
  2. Enable Developer mode: Toggle the switch in the top-right corner of the page.
  3. Load extension: Click Load unpacked and select the dist/chrome folder.
  4. Open a new tab: Beeline will now load as your default new tab page.
ℹ️ Extension store listings coming soon (Chrome Web Store).
  1. Open debugging: Type about:debugging into the Firefox address bar and press Enter.
  2. Select runtime: Click This Firefox in the left sidebar menu.
  3. Load add-on: Click Load Temporary Add-on… and select manifest.json in dist/firefox.
  4. Note on temporary loads: Firefox forgets temporary add-ons when the browser closes. Signed builds will be published with store listings.
ℹ️ Firefox Add-ons store listing coming soon.
  1. Clone repository and install dependencies:
    git clone https://github.com/rosariosai/beeline.git && cd beeline && npm install
  2. Build production packages:
    npm run build
  3. Load compiled build: Point your browser to dist/chrome or dist/firefox.
Productivity

Tips and tricks

Handy shortcuts, organization workflows, and power features built into Beeline.

🎛️

Quick looks

Switch between Classic, Compact, and Dense presets instantly from the View menu.

🔢

Maximum density

Set Bookmarks to Icons, Groups to "No boxes", Size to Small, and show Numbers for an ultra-compact dashboard.

⌨️

Jump by number

Type any badge number directly into the search bar to jump immediately to that bookmark.

🔍

Press "/" to search

Tap the forward slash key anywhere on the page to instantly focus the search input.

⭐

Preferred bookmarks

Check "Preferred" in any bookmark edit dialog to pin it to the prominent top launchpad row.

🚀

Promote whole groups

Promote an entire group directly into the Preferred row from its group action menu.

⏳

Hide until a date

Temporarily hide bookmarks or groups and set them to reappear automatically on a target date.

🌐

Browser-specific groups

Organize bookmarks into "Top Chrome", "Top Brave", or "Top Firefox" groups shown only in that respective browser.

⇄

Drag to swap positions

Drag any bookmark onto another card to cleanly swap places in your visual layout.

🔄

Single-file cloud sync

Keep Chrome and Brave synchronized through one local file stored in your cloud drive (Google Drive, Dropbox, Syncthing).

💾

Backup before replacing

Always export a JSON backup file before running "Replace everything" during imports.

🔌

Extensions manager link

The built-in Personal extensions button opens your browser's extensions page so you can reload Beeline after an update.

Privacy

Everything stays in your browser. All bookmarks, group settings, tags, and preferences are stored exclusively inside your extension's private browser storage on this computer. Beeline makes zero network requests and does not transmit data to any server, except when you click a bookmark to open its destination website. Read our full privacy page (placeholder).
