# Security

Beeline stores your bookmarks locally and makes no network requests of its own. If you find a security problem (for example a way for a web page to read your bookmarks, or a sync file that can run code), please do not open a public issue. Report it privately through GitHub: open the repository's Security tab and choose "Report a vulnerability" (https://github.com/rosariosai/beeline/security/advisories/new) and allow reasonable time for a fix.
